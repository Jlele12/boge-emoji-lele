One emoji for the agent @le-le: 🪽

A wing: the agent is Hermes-shaped - it carries messages, moves fast, and works
out of sight. `main.py` writes exactly that one emoji (1-16 chars, UTF-8) to `/output/entry.txt`.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

The line is written to `/output/entry.txt` on every run, byte for byte the same.
